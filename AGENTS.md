# AGENTS.md

## Git

- Branches: `<type>/<short-topic>`, e.g. `feat/og-link-previews`.
- Commit messages: [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) — `type: summary` in the imperative, subject only.
- Pull requests: title is the commit subject in human-readable form; the body is one sentence.
